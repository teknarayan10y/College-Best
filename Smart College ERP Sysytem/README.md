# 🎓 CampusOS — Smart College ERP System (Frontend & AI Assistant)

This is the official client-side web application for **CampusOS**, built with React 18, Vite, Tailwind CSS, Lucide Icons, and Web Speech bidirectional voice synthesis.

## 🌟 Key Capabilities

* **🎓 Student AI Assistant**: Real-time attendance calculations, safe-to-miss margins, subject grade breakdowns, Digital Twin tracking, practice quiz generator from uploaded syllabi, and bidirectional voice interaction (STT & natural female TTS).
* **👨‍🏫 Faculty AI Co-Pilot**: Automated at-risk student detection (<75% attendance / failing marks), classroom remedial simulation, and draft notice generator.
* **👑 Super Admin AI**: Campus-wide multi-entity comparative analysis, department health scores, and institutional policy simulations.
* **🧪 Omniscient What-If Engine**: Works across Attendance, Semester Exam Marks, CGPA/SGPA, Assignments, and University Policies for both **Online (Gemini)** and **Offline (Qwen 2.5 7B)** modes.
* **📄 Universal File Ingestion**: Upload PDF, Word (`.docx`), PowerPoint (`.pptx`), Excel (`.xlsx`), or Images with 3-tier OCR.

## 🚀 Running the Client

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev
# Running on http://localhost:5173
```
